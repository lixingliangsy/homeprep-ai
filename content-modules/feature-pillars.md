# HomePrep AI — Feature pillars

## Core engine
- Turns home type and timeline into a prioritized prep checklist
- Orders fix, declutter, and stage work by photo and showing impact
- Budget-friendly tips that favor low-cost prep over renovations

## Workflow & output
- Homeowners and agents get a photo-ready plan without a full stager
- Timeline-based so the plan matches the days before photos
- Before-photos tips included for listing day

## Trust & control
- Decision-support for listing prep — not a renovation quote or appraisal
- No fabricated sale-price or days-on-market claims
- Demo mode without a live API key
